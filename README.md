# 🚗 Relíquia sobre Rodas — Catálogo de Carros Antigos

Um projeto web dedicado aos apaixonados por automóveis clássicos, reunindo modelos históricos e informações sobre a evolução dos carros em uma interface visual personalizada.

## 📖 Sobre o projeto

O **Relíquia sobre Rodas** apresenta carros antigos e explora a história do automóvel por meio de uma página principal e páginas dedicadas a modelos clássicos. A interface combina textos, imagens e recursos visuais personalizados.

## ✨ Funcionalidades

- 🚘 Apresentação de carros antigos.
- 🏁 Seção sobre a história do automóvel.
- 🖼️ Páginas dedicadas ao Opala, Mustang, Brasília, Escort e Camaro.
- 🎨 Interface personalizada com CSS.
- 🔤 Uso de fontes personalizadas do Google Fonts.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização do conteúdo.
- **CSS3:** cores, tipografia e layout.
- **Google Fonts:** fontes personalizadas.

## 🚀 Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/projetoCarros.git
   ```
2. Entre na pasta:
   ```bash
   cd projetoCarros
   ```
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para executar a página estática.

## 🎯 Objetivo de aprendizagem

Praticar HTML e CSS, organizar várias páginas conectadas e desenvolver uma interface visual para apresentar conteúdo histórico.
